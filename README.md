# Roberto Catalano — Personal website

A lightweight editorial website built with plain HTML, CSS and JavaScript.

- `index.html`: homepage
- `writing/`: long-form articles
- `about/`: author information
- `assets/`: styles and site behaviours
- `.github/workflows/pages.yml`: GitHub Pages deployment

The workflow deploys the repository root to GitHub Pages on every push to `main`. In repository settings, select **Pages → Build and deployment → Source → GitHub Actions**.
